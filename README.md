# SoftwareArchitecture

This project is a simple **.NET 9 Web API** application developed for the *Software Architecture* course.

The main purpose of this project is to demonstrate:
- Clean project structure
- RESTful API development
- OpenAPI documentation usage
- Git version control with proper branching and commits

---

## 🚀 Technologies Used

- **.NET 9**
- **ASP.NET Core Web API**
- **OpenAPI (Microsoft.AspNetCore.OpenApi)**
- **Git & GitHub**
